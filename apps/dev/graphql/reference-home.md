# Schema Reference

The pages under this section are generated directly from the live
`backend/schema.graphql` at build time (via `@graphql-markdown`), so they always match
the deployed schema — every query, mutation, type, input, and enum, with its fields and
descriptions.

Use the sidebar to browse by category (Queries, Mutations, Objects, Inputs, Enums, Scalars), or
jump into the **[Sandbox](/graphql-sandbox)** to run any of these operations interactively with
schema-aware autocomplete.

New to the API? Start with the **[Overview](../overview.md)** for endpoint, transport, and
conventions, and **[Authentication](../authentication.md)** for how to present a token.
